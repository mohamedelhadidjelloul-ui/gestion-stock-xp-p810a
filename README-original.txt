GESTION STOCK - Rebuilt v1

HTML/CSS/JS only. Shared Supabase database. Arabic/French. Mobile UI. Product barcode scanner.

1) Run schema.sql once in Supabase SQL Editor.
2) Deploy index.html to Netlify (or any HTTPS static host).
3) Open the same URL on multiple phones.

The app uses per-record rows in public.app_data, so products, sales, entries and expenses are shared across devices.
