# Gestion Stock — Android + Xprinter XP-P810A

هذا المشروع يحوّل تطبيق الويب الأصلي إلى تطبيق Android حقيقي، مع طباعة الفواتير من داخل التطبيق إلى طابعة Xprinter XP-P810A عبر Bluetooth/ESC-POS.

## الاستخدام
1. ثبّت APK الناتج على الهاتف.
2. شغّل XP-P810A.
3. من إعدادات Bluetooth في Android اقترن بالطابعة (عادةً PIN: `0000`).
4. افتح التطبيق واضغط زر 🖨️ أو افتح الإعدادات > طابعة XP-P810A.
5. اختر الطابعة المقترنة واحفظها.
6. أنشئ عملية بيع كاملة واضغط **طباعة الفاتورة**. التطبيق يحوّل الفاتورة إلى صورة 576 نقطة/سطر ويرسلها كـ ESC/POS، ما يحافظ على العربية والفرنسية كما تظهر في الفاتورة.

## بناء APK من الهاتف
افتح هذا المشروع في GitHub ثم شغّل workflow:
**Actions → Build Android APK → Run workflow**.
بعد انتهاء البناء، نزّل artifact باسم `Gestion-Stock-XP-P810A-debug` ثم ثبّت `app-debug.apk`.

## ملاحظات
- الطباعة تحتاج Bluetooth مفعلاً والطابعة مقترنة بالنظام.
- التطبيق يستخدم Bluetooth Classic SPP مع أوامر ESC/POS.
- التطبيق الأصلي وSupabase وقراءة الباركود محفوظة.
